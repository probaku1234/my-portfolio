# My Portfolio

My personal portfolio website.

A single-page site built with React Router (SSR), TypeScript and Tailwind CSS. Blog posts and open-source contributions are fetched on the server from Hashnode's RSS feed and the GitHub API.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Editing content

All site copy lives in `app/content.ts`.
